# Niagara development portfolio

Single-page portfolio for bespoke Niagara Framework module development, served
by GitHub Pages from `main`.

- `index.html` — the whole site, self-contained, no build step and no dependencies.
- `img/` — screenshots of the `iosUi-ux` and `rocketGx-ux` bajaux widget sets,
  rendered from the preview harness in `~/niagara/ux`.

## Before sharing this link

1. Replace `REPLACE@EXAMPLE.COM` in the footer with the real contact address.
2. Delete the `<meta name="robots" content="noindex">` line in `<head>` so the
   page can be indexed.

## Honesty rules for this page

The screenshots are from a demonstration station and the page says so. Nothing
here claims a client deployment, a certification or an affiliation we do not
have. Keep it that way — the buyers are engineers and they check.
