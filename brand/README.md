# Plantroom Labs — brand kit

Everything here is generated by two scripts. Nothing was drawn by hand, so a
colour or a spacing decision is changed in one place and every file follows.

---

## The mark

A plumbed heat-exchanger coil: an inlet stub enters low-left, the flow takes
two 180° bends through the bank, an outlet stub leaves high-right. Drawn on a
32-unit grid with 180° rotational symmetry.

The stubs are load-bearing, not decoration. Earlier passes drew the bends on
their own and the closed silhouette kept resolving into a letter — a "2" with
two turns, an "N" or an "M" with three. Breaking the figure open at both ends
is what stops a reader seeing type.

Below about 20px the two terminal nodes thicken the stub ends into blobs and
the coil loses a turn, so the small sizes use a second drawing: no nodes,
heavier stroke (`mark-small.svg`, `badge-dark-small.svg`). Same silhouette,
one fewer thing to render. `favicon.ico` carries three separate drawings —
16, 32 and 48 — rather than one bitmap downscaled twice.

## Colour

| Role | Light | Dark | Token |
|---|---|---|---|
| Accent | `#7b61ff` | `#9b85ff` | `--gx-run` |
| Ink / canvas | `#0e1116` | — | `--gx-n-99` |
| Paper | `#ffffff` | — | — |
| Muted (tagline) | `#5f6b7c` | `#97a2b3` | `--gx-n-70` |

The dark-theme accent is lifted a step because `#7b61ff` on `#0e1116` sits
under the contrast floor and reads as a glow rather than a colour.

## Type

Inter Display SemiBold throughout. The wordmark is tracked `-0.015em`
(`--gx-track-title`); the tagline is micro-caps at `+0.14em`, which it needs
or "NIAGARA FRAMEWORK ENGINEERING" reads as one word.

All type in these files is **outlined**. A recipient with no Inter installed
still sees the correct logo.

## Which file to use

| Situation | File |
|---|---|
| Website nav, light background | `logo-horizontal-light.svg` |
| Dark background, padded | `logo-horizontal-dark.svg` |
| Tight horizontal space | `logo-horizontal-notag-*.svg` |
| Business card, sticker, panel | `logo-stacked-*.svg` |
| Invoice, fax, laser etch, embroidery | `logo-horizontal-black.svg` / `-white.svg` |
| Avatar — GitHub org, LinkedIn, Workspace | `png/avatar-1000.png` |
| App icon / PWA | `png/icon-192.png`, `png/icon-512.png` |
| iOS home screen | `png/apple-touch-icon.png` |
| Browser tab | `png/favicon.ico`, `badge-dark-small.svg` |
| Anywhere you need just the symbol | `mark.svg` (uses `currentColor`) |

`@2x` PNGs are for anything that will be viewed on a retina display or
printed. Everything else should use the SVG.

### Clear space and minimum size

Keep clear space of one mark-width on every side of a lockup. Minimum
reproduction: 24px tall for the horizontal lockup with tagline (below that
the tagline fills in), 16px for the mark alone using the small drawing.

### Don't

Recolour the mark outside the palette above; stretch a lockup
non-proportionally; re-typeset the wordmark in another face; put the
light-theme accent on the dark canvas; add a drop shadow or a gradient.

## Rebuilding

```bash
python3 -m venv .venv && .venv/bin/pip install uharfbuzz fonttools cairosvg pillow
INTER_DISPLAY_SEMIBOLD=/path/to/InterDisplay-SemiBold.otf .venv/bin/python mklogo.py
.venv/bin/python mkpng.py
```

`mklogo.py` writes the SVGs (the font is only needed here — it shapes the
wordmark with real kerning and converts it to paths). `mkpng.py` rasterises
them with cairosvg; ImageMagick is deliberately not used, because there is no
librsvg delegate on the build machine and `convert` would re-parse the file
with its own SVG reader and lose the rounded joins.

`preview.html` is a contact sheet of every file at every size it has to
survive. Open it after any change.

The site consumes this directory rather than keeping its own copy:
`build_mark()` in `../build.py` copies the badge and the favicon set into
`assets/`, and the inline nav mark reuses the same path data. Change the
geometry here first.
